## 数据维护

在电脑上打开随交付包提供的“本地更新工具/更新网页.html”，选择已刷新保存的Excel，核对数据后生成index.html。在此仓库选择Add file → Upload files，上传并覆盖index.html，提交到main分支。GitHub Pages部署完成后，刷新原网址查看新版。

发布权限由GitHub仓库写权限控制，访客无需登录。仓库仅包含网页展示数据，原始Excel保留在维护者电脑上，请勿将原始工作簿上传至公开仓库。
